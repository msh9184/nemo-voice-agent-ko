# Logo Images

Place the company logo PNG files here:

- `logo_white.png` - White text logo (for dark theme)
- `logo_black.png` - Black text logo (for light theme)

## Source Location

Copy from GPU server:
```bash
cp /path/to/workspace \
   /path/to/workspace
```

Or from local (if synced):
```bash
cp examples/voice_agent/images/logo_*.png examples/voice_agent/client/public/images/
```

## Theme Behavior

- **Dark theme** (default): Shows `logo_white.png`
- **Light theme**: Shows `logo_black.png`
